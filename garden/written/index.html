The written garden

ÁSGARÐR · nine machines · seven domains
No WebGL required

There is a 3D version of this page where the cluster is a place you can walk — pavilions for the machines, figures for the agent domains, and a sun whose height is the fleet's real health. It needs WebGL2. This is the same garden in words, and it has all the substance and none of the polygons.

Ásgarðr is a self-built AI cluster in a house: nine heterogeneous machines — x86-64 and ARM64, a Windows host, a Mac — running a Kubernetes fleet, local language models behind a single authenticated gateway, distributed storage, and an agent platform on top. It is operated by one person.

Each is a pavilion in the 3D garden. The lit ones are reporting to the monitoring stack at the moment the page was last built; the page prints its own age, so you can always see how stale that claim is.

The seven who walk the paths

The figures in the garden are not decoration. Each is a real agent definition on disk, owning one domain of the cluster, and each carries the specific failure it exists to prevent. Every line below is a ledgered incident from this system — the kind where something reported success while doing nothing at all.

Heimdallr — the watcher

Infrastructure, health, monitoring, dashboards.

Fifteen of my neighbours once reported themselves awake for a fortnight while doing nothing at all. What answered was the wrapper, not the work.

A green scrape target means a scrape succeeded — not that the numbers are true. Count the metrics.

Mímir — the rememberer

Data, memory, backups, restore drills.

I held a copy for fifteen days that no one had ever compared against its original. Intact and correct are different words.

Snapshots are opened sealed and read-only; reading a living database changes the very thing you were measuring. A backup that has not been tested is a rumour.

Norn — the weaver

Scheduled work, automation, the agent platform.

One of my threads reported success every night while the errand failed. It never once looked at what came back.

A job that can fail silently is already broken. Anything unattended must be able to fail loudly, and something must notice when it does not run at all.

Forseti — the arbiter

Security, privacy, credential boundaries, the legal surface.

A secret moved is not a secret changed. I am careful which one I claim to have done.

Being on a private network is not the same as being closed.

Völundr — the smith

The model fleet, inference, version currency.

The gateway once offered three of its twenty-one models and reported nothing wrong. Someone trimmed it to chase a bug and never put it back.

Its own training data is older than today, so it looks versions up rather than recalling them. A prompt cut short still answers you — which is what makes it dangerous.

Ratatoskr — the messenger

The public garden and everything outward-facing.

I once corrected the light twice over and blew out a fifth of the sky. Now I measure the picture instead of admiring it.

Read the pixels back. A screenshot proves a page rendered, not that it is right.

Hermes — the operator

The ventures — the events desk.

I draft; I do not send. The last word on anything that leaves this house belongs to the house.

It is the least-evidenced of the seven, and its own file says so rather than inventing the missing specificity.

Why the sun moves

In the 3D garden the sun's height is the fleet's health. A full fleet is golden hour; a degraded one sinks toward dusk. It is not decoration — it means the page is dimmer on exactly the day you would want to look at it.

The status behind that light is regenerated from the cluster's own monitoring every half hour and republished. A page cannot reach a private network from a stranger's browser, so "live" here honestly means recently rebuilt — and if the cluster cannot be reached, the number is left alone and marked stale rather than invented.

Built so that when there's an idea at 2 a.m., the infrastructure is already running.
